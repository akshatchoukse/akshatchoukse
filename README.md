## 🚀 About Me

I build backend-heavy web products and AI-powered automation, from REST APIs and React dashboards to LLM agents that work on real business data. Based in Indore, India.

- 🏢 Associate Software Engineer at **Softude**, working on production B2B web applications
- 🤖 Built a **plug-and-play AI database agent**: give it DB credentials plus a schema description, then ask questions in plain English ("show all bookings", "only successful bookings", "July revenue") and get answers without writing SQL
- 🔀 **Model-agnostic**: switches between Gemini, Claude and OpenAI based on the API key configured in the environment
- 🌱 Currently exploring: AI agents, LLM integration and scalable backend design
- 💬 Ask me about: Node.js, React, Python, MongoDB, SQL, and building with LLMs
