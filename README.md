### 🧠 Flagship Build: Plug-and-Play AI Database Agent

An agent you point at **any database**: give it **DB credentials + a schema description**, then talk to your data in plain English.

```text
You   >  show all bookings
You   >  only successful bookings
You   >  July revenue
Agent >  runs the right query and answers, no SQL written by you
```

| Capability | Details |
|---|---|
| 🗣️ **Natural language to answers** | Business users query data without knowing SQL |
| 🔀 **Model-agnostic** | Switches between **Gemini, Claude and OpenAI** based on the API key set in the environment |
| 🔌 **Plug and play** | Credentials plus schema description is all the setup it needs |
| 🏢 **Built for real data** | Designed around live business data such as bookings and revenue |
